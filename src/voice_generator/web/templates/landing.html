voice-generator

Local, fully FOSS voice cloning from a text script — Stage 1 of the AI Digital Twin pipeline. Give it a short recording of a voice and a text script; it renders the script in that voice to a WAV file, entirely on your own machine. Zero APIs, zero cloud.

Listen to the samples Get the code

How it works

  1. Chunk — split the script on sentence boundaries (up to 300 chars per chunk).
  2. Validate — check the reference clip (length, channels, sample rate) before synthesis starts.
  3. Synthesize — the backend loads its model once and renders each chunk to PCM-16 WAV.
  4. Join + manifest — chunks are concatenated sample-accurately, and a .manifest.json is written beside the WAV, recording exactly which backend, reference clip, and settings produced it. That manifest is the contract with Stage 2 (the audio-driven talking head).

Four engines behind one CLI

The TTS field moves monthly, and the candidate models have wildly different licenses and install stories. One interface means you can compare engines on your own voice and script and swap later without touching the CLI, the chunking, or Stage 2. Backends live in separate environments because they pin conflicting torch/CUDA stacks — they are never installed into the same environment, and the core package itself has no torch dependency.

voxcpmWorking (v0.4)Apache-2.0~5–10 s, no transcript (controllable); + transcript (ultimate)~8 GB (vendor)

Which to start with: Chatterbox — easiest install, no transcript bookkeeping. Qwen3-TTS next for a smaller/faster Apache-2.0 model. VoxCPM2 is the fast path to benchmark: one-line pip install, no transcript in its default mode, vendor RTF ~0.30 on a 4090 (no RTX 3060 figure published yet — measure it before trusting it). CosyVoice 3 for multilingual work or Chinese dialects, accepting the hardest install.

Explicitly not included, after license research: Fish Speech (non-commercial weights), IndexTTS-2 (custom bilibili license), F5-TTS / Spark-TTS (non-commercial weights), and “Breeze TTS 2” (no FOSS release found — only a proprietary hosted API). The full survey of alternatives, and why they were ruled in or out, is on the research page.

Try it

py -3.11 -m venv .venv-core
.venv-core\Scripts\activate
pip install -e .
voice-gen synth --backend mock --text "Hello world. This is a plumbing test." --out output\smoke.wav

That proves the pipeline with no GPU and no model downloads. The ordered path from there to hearing your own cloned voice is SETUP.md in the repo; the full reference is the README.
