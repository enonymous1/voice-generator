Synthesize

Paste text, pick a backend and a reference clip, and render. The render runs in the background — this page takes you to the job, and you can listen and download from there. The transcript for a clip comes from refs/<name>.txt when the Setup page stored one.

Mock renders a 220 Hz test tone, not speech — its length follows the text (about 1 second per 14 characters). It only checks the plumbing: chunking, WAV writing and the manifest. Pick a real backend and a reference clip for an actual voice.

The voice the backends clone from. Record or upload a clip on the Setup page first if you haven't — a reference is required for every real backend. Only the mock backend renders without one.

Full cloning uses the clip’s transcript when one is attached; without it, the render falls back to x-vector-only (lower quality).

The script is split into chunks of at most this many characters — on sentence boundaries where possible — and each chunk is rendered separately, then the audio is joined back together. Smaller chunks use less memory per render but add more joins; larger chunks flow better, but each one is a bigger job for the model. 300 is the default.

Local only — this UI binds localhost and never sends audio anywhere. Renders live in output/; reference clips live in refs/.
