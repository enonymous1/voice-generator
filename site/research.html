Fast, open zero-shot voice-cloning TTS

Researched 2026-11-10. Hardware in scope: Windows, RTX 3060 12 GB VRAM, 64 GB RAM; English text scripts → WAV, offline; speed matters more than multilingual coverage. Baseline already owned (not re-reported as discoveries): Chatterbox Turbo (MIT), Qwen3-TTS 1.7B Base (Apache-2.0), CosyVoice 3 (Apache-2.0, hardest Windows install). The full per-candidate notes live in the repo at docs/research/fast-open-voice-cloning-tts-2026-11-10.md.

Recommendation: add VoxCPM2 as the fourth backend — the only candidate that is simultaneously (a) genuinely permissive for code and weights, (b) fast on a vendor-measured basis, (c) a one-line PyPI install, and (d) fits a 12 GB card at ~8 GB VRAM. Confidence: moderate-high on licence/install/speed-claim; moderate on real-world RTX 3060 speed and English clone quality, which still need a local A/B against Chatterbox/Qwen3-TTS. It shipped in v0.4.0.

How to read speed figures

RTF = compute seconds ÷ audio seconds (RTF 0.3 ≈ 3.3× real-time; RTF 2.1 = slower than real-time). Some sources invert this as RTFx = audio ÷ compute (RTFx 3× = RTF 0.33). Almost all GPU figures are vendor claims on an RTX 4090/H100, not on an RTX 3060 — no reliable RTX 3060 figure was found for any candidate. Do not extrapolate 4090 → 3060 linearly.

1. VoxCPM2 (OpenBMB) — added in v0.4.0

  • Licence: Apache-2.0 for weights and code, “free for commercial use” — verified live on PyPI, 2026-11-10. pypi.org/project/voxcpm
  • Speed: vendor table (RTX 4090, concurrency 1, inference_timesteps=10, torch.compile on): RTF ~0.30 standard, ~0.13 with Nano-vLLM; VRAM ~8 GB. That is ~3.3× real-time standard, ~7.7× with Nano-vLLM — on a 4090. No RTX 3060 figure found.
  • Windows install: pip install voxcpm; Python ≥3.10 (<3.13), PyTorch ≥2.5.0, CUDA ≥12.0. Known landmines: Triton-on-Windows (install triton-windows or pass optimize=False to skip torch.compile); Could not load libtorchcodec with reference audio (torchaudio ≥2.9 defaults to torchcodec — install system FFmpeg or force the soundfile backend).
  • Cloning: controllable cloning from a short reference clip, no transcript; “Ultimate Cloning” (clip + exact transcript) for maximum similarity; 30 languages, 48 kHz out, accepts 16 kHz reference.

2. GPT-SoVITS v2ProPlus — fastest measured, messiest to integrate

  • Licence: MIT for the framework code; secondary sources warn base-model files and some dependencies carry their own licence notes — check the specific checkpoint.
  • Speed: fastest vendor-published RTF in this survey, from the project README: v2ProPlus RTF 0.028 on RTX 4060 Ti, 0.014 on RTX 4090 (1,400 words ≈ 4 min audio in 3.36 s), 0.526 on M4 CPU. A separate guide measured v4 inference RTF ~0.5 on RTX 5080 — version matters enormously.
  • Windows install: best Windows story of the heavy models: integrated package, double-click go-webui.bat; or Conda + install.ps1. No PyPI package — it is a WebUI/API toolkit, not a library, so integrating it into a CLI means driving its API/WebUI or vendoring its inference code.
  • Cloning: zero-shot from 5 s of audio; its real strength is few-shot fine-tuning (~1 min of data trains a voice model) — not this project’s workflow (3–10 s clip, no training). For pure zero-shot, the prompt needs audio and its transcript.

3. Pocket TTS (Kyutai) — fastest on CPU, lightest, gated cloning

  • Licence: code MIT; weights CC-BY-4.0 (permissive, commercial use allowed with attribution). Two preset voices (jean/cosette) are CC-BY-NC-4.0 — irrelevant if you only use cloning.
  • Speed: ~6× real-time on a MacBook Air M4 using only 2 CPU cores, ~200 ms first-chunk latency, 100M params, 24 kHz. Independent tts-bench (Windows Ryzen 9 9950X3D CPU): TTFA warm 97–150 ms, RTFx warm 2.9–3.0×. GPU explicitly not recommended by Kyutai.
  • Windows install: pip install pocket-tts (PyPI 2.0.0, py3-none-any wheel). No espeak/pynini blocker found.
  • Cloning: sample-based zero-shot, no fine-tuning; 5 s is enough per Kyutai, ~20 s per community write-ups. Gated: cloning weights require accepting terms on Hugging Face and logging in; without access it silently falls back to a no-cloning build. That gate breaks a fully-offline, no-account CLI flow on first run unless weights are pre-downloaded.

Licence traps — excluded, not clean

  • XTTS v2 — CPML non-commercial weights (Coqui is gone).
  • MaskGCT — CC-BY-NC-4.0 weights.
  • ChatTTS — AGPL-3.0 code / CC-BY-NC-4.0 weights, and it samples a speaker rather than cloning one.
  • MegaTTS 3 — Apache on paper, but ByteDance withholds the WaveVAE encoder, so cloning a new speaker locally is impossible.
  • OmniVoice — Apache headline vs CC-BY-NC weights per tts-bench, plus a Higgs-derived tokenizer under the Boson Community License. Exclude until the HF card itself resolves it.
  • LuxTTS / ZipVoice — LuxTTS claims Apache-2.0, but it is a distilled ZipVoice derivative and ZipVoice’s weights carry no licence grant at all (trained on the CC-BY-NC-4.0 Emilia dataset).
  • Supertonic 3 — OpenRAIL-M weights, and the open repo has no voice-cloning pipeline (the hosted Voice Builder shut down 2026-08-31; the repo was announced for archiving July 2026).

Known traps already established before this survey (not re-reported as discoveries): Fish Speech (non-commercial weights), IndexTTS-2/2.5 (custom bilibili license), F5-TTS weights (CC-BY-NC), Spark-TTS weights (CC-BY-NC-SA), Higgs (research/non-commercial), Breeze TTS 2 (not open source — hosted API only), Wav2Lip (non-commercial).

Not zero-shot cloners — noted briefly

  • StyleTTS 2 — MIT, excellent English narration, but trained voices only; no cloning.
  • Kokoro-82M — Apache-2.0, 82M, ~10× RT on CPU, 54 preset voices — no cloning.
  • Piper / MeloTTS / KittenTTS — fixed-voice, fast, no cloning. (Piper is now GPL-3.0 — check before bundling.)

Could not verify / open questions

  • No RTX 3060 speed figure exists in public sources for any candidate. Every speed ranking above is conditional on a local 3060 measurement — that is what the listen page bench is for.
  • LuxTTS 150× claim: vendor-only, no independent bench found.
  • VoxCPM2 English clone quality vs Chatterbox/Qwen3-TTS: vendor benchmark tables only; no independent blind listening comparison on the same English clips was found.
  • GPT-SoVITS base-model licences: secondary sources flag per-file licence notes; the specific v2ProPlus checkpoint files were not re-read.
  • OmniVoice weights licence: sources conflict; the HF model card itself was not re-read — resolve there before any use.
  • Pocket TTS 1,000-character limit and exact Windows behaviour: secondary summaries only; Kyutai’s docs emphasise macOS.
  • Dia2 / MOSS-TTS-Realtime / FireRedTTS3 RTF on a 3060: no figures found; Dia2 figures conflict across sources.
  • Orpheus 1B/400M/150M models: listed as planned in 2025 announcements; no evidence they shipped as practical local models by Nov 2026.
